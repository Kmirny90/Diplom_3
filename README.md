# Diplom_3

UI-тесты Stellar Burgers

## Описание
Автотесты для проверки пользовательского интерфейса приложения Stellar Burgers (космический фастфуд).

## Документация
- [Stellar Burgers](https://stellarburgers.education-services.ru)
- Базовый URL: `https://stellarburgers.education-services.ru/`

## Реализованные тесты

### Основная функциональность (`test_main_functionality.py`)
- Переход по клику на «Конструктор»
- Переход по клику на «Лента заказов»
- Открытие модального окна при клике на ингредиент
- Закрытие модального окна по крестику
- Увеличение счетчика булки на 2 при добавлении
- Увеличение счетчика соуса на 1 при добавлении

### Лента заказов (`test_order_feed.py`)
- Увеличение счетчика «Выполнено за всё время» после создания заказа
- Увеличение счетчика «Выполнено за сегодня» после создания заказа
- Появление номера заказа в разделе «В работе»

## Технологии
- pytest
- selenium
- allure-pytest
- webdriver-manager
